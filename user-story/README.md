# user-story/

Drop a raw feature request or user story here (as a `.md` file) to seed
a new run of the Agentic SDLC pipeline, or pass it directly as
`$ARGUMENTS` to `/pipeline`.

No format is required — the `requirements` agent is responsible for
turning whatever is written here into structured requirements. A short
example:

```
As a user of the CLI, I want to export my report as CSV so that I can
open it in a spreadsheet tool.
```

Nothing in this directory is generated by the pipeline — it is
input-only. Generated artifacts live under `docs/`.
