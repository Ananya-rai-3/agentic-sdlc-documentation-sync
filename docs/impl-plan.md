# Implementation Plan

## Summary
Build the doc-sync stage bottom-up: deterministic Node scripts (report grammar, path guard, base/fingerprint, discovery, links) with plain-node tests first, then the two hooks, the demo module and fixtures, the five skills and the agent, and finally the wiring (settings, orchestrator preflight, prose) and an end-to-end demonstration. 25 tasks, roughly 45 hours; each task is 1-3 hours so it can be approved individually.

Conventions for every task: scripts in `.claude/scripts/doc-sync/`, plain CommonJS, no dependencies; tests flat in `tests/test-doc-sync-<area>.js` using the `check()` pattern from `test-harness-conventions`; fixtures under `tests/fixtures/doc-sync/`. Traceability is given as FR/NFR ids and design-review finding ids (C-01, H-01..H-04, M-02..M-05, L-xx).
